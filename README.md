# Вимузыка

Браузерный синтезатор для небольших композиций и живой игры. В одном окне работают два голоса: пиано с аккордовой гармонией слева и резонансное дерево справа.

**Попробовать:** [vimur-design.github.io/synthesizer](https://vimur-design.github.io/synthesizer/).

После открытия нажмите «Играть» или сыграйте ноту: браузер включает звук после действия пользователя. Все инструменты синтезируются на устройстве, аудиосэмплы и аккаунт не нужны.

## Возможности

- Общий транспорт, BPM 40–180, цикл 1–8 тактов, метроном и громкость.
- Нотный редактор для двух партий: добавление, перемещение, изменение длительности и силы нот.
- Аккорд на каждый такт и ручная игра мышью или клавишами A W S E D F T G Y H U J K.
- До трёх резонансных деревьев: рост, изменение кроны, игра по ветвям, шум, ветер и дождь.
- Автосохранение в текущем браузере, открытие и сохранение JSON, отмена и повтор изменений.

## Два голоса и эффекты

У пиано с гармонией и дерева самостоятельные цепочки: фильтр низких частот 5400 Гц, Feedback Delay (0,29 с, feedback 0,16, wet 0,12) и стереопанорама. Пиано с гармонией смещено влево (`pan = -0.35`), дерево — вправо (`pan = +0.35`). Внутренняя панорама ветвей сохраняется. После обработки голоса объединяются на общем выходе с регулятором громкости, лимитером и индикатором уровня.

Это наша модель резонансного дерева baseline 0.2, а не точная копия оригинального Tree Tone. Ручная игра звучит поверх цикла, но пока не записывается автоматически.

## Локальный запуск

Нужны Node.js 22.12+ и npm.

```sh
npm ci
npm run dev
```

Откройте http://127.0.0.1:5175/. Остановка сервера — `Ctrl+C`.

```sh
npm test
npm run build
npm run preview
```

Предпросмотр сборки доступен на http://127.0.0.1:4175/. Для статического хостинга используется папка `dist`. Относительные пути сборки поддерживают размещение в `/synthesizer/`.

## Проверка звука

При работающем dev-сервере откройте http://127.0.0.1:5175/audio-check.html. Кнопка «Проверить звук» запускает 15 offline-сценариев, включая измерения левого и правого каналов. «Проверить AudioWorklet вживую» проверяет 11 сценариев запуска, mute, Pause и Stop. Отдельная кнопка проверяет работу секвенсора и аудиочасов. Проверки AudioWorklet и мелодии воспроизводят звук.

Node-тесты проверяют музыкальную модель, геометрию и звуковое ядро. Для ручной проверки в наушниках сыграйте пиано, затем ветви: пиано должно ощущаться левее, дерево — правее. Проверьте совместное воспроизведение и остановку.

## Публикация GitHub Pages

Workflow `.github/workflows/deploy.yml` устанавливает зависимости через `npm ci`, запускает тесты и сборку, затем публикует `dist`. Он выполняется при изменениях в `main` и вручную из вкладки Actions.

В Settings → Pages источником публикации должен быть выбран **GitHub Actions**. После успешного workflow сайт доступен по ссылке в начале README. Посетителям не требуется запускать локальный сервер.

## Структура

- `index.html` — окно с двумя голосами.
- `src/javascript/studio.js` — состояние интерфейса и редактор нот.
- `src/javascript/model.js` — ноты, аккорды и формат проекта.
- `src/javascript/audio-engine.js` — синтезаторы, транспорт и отдельные цепочки эффектов.
- `src/javascript/forest-model.js` — рост дерева и параметры резонаторов.
- `src/javascript/forest-view.js` — SVG-сцена и управление деревьями.
- `src/javascript/forest-audio.js` и `forest-worklet.js` — звуковое ядро дерева и его выполнение в аудиопотоке.
- `src/stylesheets/` — стили интерфейса.
- `tests/` — проверки модели и DSP.

Стек: JavaScript, Vite, Tone.js, Web Audio API, HTML/CSS/SVG.
